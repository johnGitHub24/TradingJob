功能流程說明 — TradingJob

衝突以主規格為準。

流程清單

ID 流程 入口 結果
F-A 逾時取消 Cron JOB-A / POST .../stale-order-cancellation 取消筆數
F-B PnL 快照 Cron JOB-B / POST .../pnl-snapshot 寫入快照筆數
F-C 失敗重試 Cron JOB-C / POST .../failed-command-retry 重放成功筆數
F-D 資料清理 Cron JOB-D / POST .../cleanup 刪除事件＋失敗指令

F-A 步驟

1. Scheduler / Client → StaleOrderTimeoutJob 或 JobController
2. StaleOrderCancellationService 查逾時未成交訂單（timeout-seconds、batch-size）
3. 更新狀態為取消並寫事件（若有）
4. 回傳 JobRunResponse

F-C 步驟（含外部）

1. FailedCommandService 取出到期 PENDING／可重試指令
2. OrderReplayPort 重放下單（本機 InProcess 或 Engine HTTP）
3. 成功→終態；失敗→ attempts++、排程 next_retry_at；超過 max-attempts → 終態失敗
