# 資料庫設計 — TradingJob

> 衝突以主規格為準。規範：EngineeringOS `knowledge/database-design.md`

## 1. 存取鏈

```text
Controller / Scheduler → Service (@Transactional) → Repository → H2 / PostgreSQL
```

## 2. 資料表

| 表 | 用途 | 重要約束／說明 |
|----|------|----------------|
| `orders` | 訂單（逾時取消讀寫） | 狀態、建立時間 |
| `positions` | 持倉（PnL 快照來源） | 依 symbol |
| `pnl_snapshots` | JOB-B 輸出 | 快照日 + symbol |
| `failed_commands` | JOB-C DLQ | status、next_retry_at、attempts |
| `order_events` | 審計事件（JOB-D 清理） | 保留天數可設定 |

## 3. Entity 對照

| Entity | 表 |
|--------|-----|
| `OrderEntity` | `orders` |
| `PositionEntity` | `positions` |
| `PnlSnapshotEntity` | `pnl_snapshots` |
| `FailedCommandEntity` | `failed_commands` |
| `OrderEventEntity` | `order_events` |

## 4. 環境

| Profile | DB | 設定 |
|---------|-----|------|
| 預設 | PostgreSQL | `application.yml` + env |
| `dev` / `test` | H2 | `application-dev.yml` 等 |

## 5. SQL 驗證（H2／PG）

```sql
-- 確認核心表存在（依環境調整）
-- H2: SHOW TABLES;
SELECT TABLE_NAME FROM INFORMATION_SCHEMA.TABLES
WHERE TABLE_NAME IN ('ORDERS','POSITIONS','PNL_SNAPSHOTS','FAILED_COMMANDS','ORDER_EVENTS');
```
