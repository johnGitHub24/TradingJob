TradingJob — API 文件

排程任務：JOB-A 逾時取消 · JOB-B PnL 快照 · JOB-C 失敗重試 · JOB-D 資料清理 · Spring Boot 3 · Java 21 · @Scheduled

CodeGraphic architecture.md Task 用法 Runtime Swagger UI（:8084 dev）

啟動與位址

啟動（dev／H2）.\gradlew.bat bootRun（預設 dev profile，H2，免 PostgreSQL）
Port8084（dev profile；default yml 為 8083，走 PostgreSQL 與 Engine 共用 DB）
OpenAPI JSONhttp://localhost:8084/v3/api-docs
Swagger UIhttp://localhost:8084/swagger-ui.html
H2 Consolehttp://localhost:8084/h2-console（JDBC jdbc:h2:mem:tradingjob，帳號 sa，密碼空白）
驗證.\gradlew.bat check（unit + integration）

API 分組（實際 Controller）

  • Jobs 手動觸發：POST /api/v1/jobs/stale-order-cancellation（JOB-A）、POST /api/v1/jobs/pnl-snapshot（JOB-B）、POST /api/v1/jobs/failed-command-retry（JOB-C）、POST /api/v1/jobs/cleanup（JOB-D）
  • 查詢：GET /api/v1/pnl-snapshots、GET /api/v1/failed-commands
  • 四個 Job 另有 cron 排程（trading.job.* 設定；dev profile 縮短為每 1～5 分鐘方便觀察）。

認證與範例流程

  • 無認證（無 Spring Security／JWT），啟動後可直接呼叫。
  • 範例：POST /api/v1/jobs/pnl-snapshot 手動觸發快照 → GET /api/v1/pnl-snapshots 查結果；POST /api/v1/jobs/failed-command-retry → GET /api/v1/failed-commands 看重試佇列。
  • 正式環境（default yml，:8083）與 Engine 共用 PostgreSQL；本機驗證用 dev／H2，不假設 Engine 已啟動。

本頁載入 http://localhost:8084/v3/api-docs（dev profile 實際埠）。若你以 default profile 啟動（PostgreSQL），埠為 8083，請自行改網址。 若以 file:// 直接開啟本頁而無法載入，請改用 http://localhost:8084/swagger-ui.html，或在 docs 目錄啟一個靜態伺服器（例如 python -m http.server）。
